# Hackathon Toolfinder · Teva Finance Hackathon

A single-page guide that helps hackathon teams pick the right **approved Teva tools** for their solution.

- **Find my stack** – answer 4 questions (goal, data, team skills, sensitivity) and get a recommended stack laid out as Capture → Store → Process → Deliver, plus guardrails, pitch kit, first steps, watch-outs, SMEs to ask for, and a copyable brief for the Technical Guidance drop-in.
- **Finance blueprints** – 10 common finance use cases (invoice exceptions, close tracker, variance commentary, cash forecast…) that pre-fill the finder.
- **Tool landscape** – the full approved catalog with search, lifecycle-status and fit × skill filters, and a detail drawer per tool.
- **Which one?** – side-by-side picks for commonly confused tools.

Open `index.html` in a browser. No build step, no dependencies. `app.html` is the same page without the document wrapper (used for publishing as a Claude artifact).

Tool data and status come from the approved catalog shared with participants. Copilot Studio is flagged "Confirm access": it is named in the invitation but not in the catalog.
